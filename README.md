# 나갈깍? (실시간 시험판)

올림픽공원 주차장에서 공연이 끝난 뒤 언제 나가면 좋은지, 지난 입출차 기록으로 알려 주는 안내 화면입니다.

- 주소: https://kucaver.github.io/olympicpark-exit-live/
- 기본판: https://kucaver.github.io/olympicpark-exit/ (이 시험판은 기본판에 실시간 주차 대수 칸을 더한 것입니다)
- 서버 없이 도는 정적 페이지입니다. `data/days.json`은 미리 계산한 결과입니다.

## 쓴 자료

- 한국체육산업개발 올림픽공원 2025 입출차정보 (문화공공데이터광장 API_CPM_008, 2025-01-01~12-07, 매달 말일과 11-08~11-30은 기록 없음)
- 올림픽공원 2025 차량입출차·공연·날씨정보 등 연계 데이터 (문화공공데이터광장 API_CPM_009, 관람객 수와 공연 시간대)
- 공연정보(통합) 가운데 한국체육산업개발 공연 (문화공공데이터광장 API_CCA_144)
- 한국체육산업개발 실시간 주차현황 (공공데이터포털 15168686). 요청 주소는 기관 누리집 안내 페이지에서 화면이 열릴 때 읽으며, 이 저장소에는 키를 싣지 않았습니다. `data/live_model.json`은 2025 기록으로 맞춘 직선 식입니다.
- 주차 요금: 올림픽공원 주차 안내 (2026-11-12 확인)
- 지하철·버스 기본요금: 서울교통공사 운임 안내, 서울시 공공요금 자료 (2026-11-12 확인)

원자료는 싣지 않았고, 날짜별로 묶은 결과만 들어 있습니다. 지난 기록으로 낸 값이라 실제와 다를 수 있습니다.
